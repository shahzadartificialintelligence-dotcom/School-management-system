# School Management System

An Advanced School Management System developed using PHP, MySQL, HTML, CSS, Bootstrap, and JavaScript.

This system is designed to manage complete school operations for both Boys Campus and Girls Campus through separate admin panels.

---

# Main Website

## Home Page
The first page of the website is an index page that displays complete information about the school management system.

After entering the website, users can select:
- Boys Campus
- Girls Campus

Each campus has its own separate login panel and dashboard system.

---

# Authentication System

## Admin Login
Admins can log in using:
- Email
- Password

After successful login, admins are redirected to their respective campus dashboard.

---

# Boys Campus Dashboard

The Boys Campus Admin can manage the complete school system.

## Admin Management
- Add new admins
- Manage admin accounts

## Student Management
- Add new students
- Store complete student information
- Upload student pictures
- Add student sibling information if already enrolled in school

## Fee Management
- Add student fee details
- Manage fee plans
- Generate and print student fee challans

## Teacher Management
- Add and manage teachers

## Class & Subject Management
- Create and manage classes
- Add subjects related to classes

## Timetable Management
- Create class timetables
- Assign teachers to timetable schedules
- Print class timetables

## Examination Management
- Manage exam dates
- Create exam timetables based on classes
- Print exam schedules

## Transport Management
- Manage transport schedules
- Print transport schedules

## Student Card Management
- Generate and download student ID cards

---

# Girls Campus Dashboard

Admins can fully manage:

# Installation Guide

## Clone Repository

```bash
https://github.com/shahzadartificialintelligence-dotcom/School-management-system.git
```

## Import Database
- Open phpMyAdmin
- Create a new database
- Import the SQL file

## Configure Database
Update database credentials in:

```php
config.php
```

## Run Project

Move the project folder into:

```bash
htdocs/
```

Start:
- Apache
- MySQL

Open in browser:

```bash
http://localhost/school-management-system
```
